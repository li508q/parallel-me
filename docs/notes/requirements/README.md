# Requirements · 原子需求

> 本目录沉淀**可独立排期、独立验收的原子需求**。

## 文件

- [backlog.md](backlog.md) — 全部原子需求总表（R 系列产品体验类 + S 系列工程改造类）

## 编号规约

- **R 系列**：产品体验/UI 类需求，来源主要是 `../experience-log/` 中的具体痛点
- **S 系列**：工程改造类需求，来源主要是 `../design-concepts/` 与 `../engineering-research/`
- 编号在 backlog.md 中**不重用**，需求完成或废弃后保留行 + 状态标注，不删除编号

## 验收标准约定

每条需求必须有"验收标准"列，要求是**可二值判定的描述**（"通过 / 不通过"），避免"提升体验"这种无法验收的措辞。
