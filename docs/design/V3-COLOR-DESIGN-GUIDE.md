# V3 Color Design Guide

![V3 Color System](./V3-COLOR-SYSTEM-DIAGRAM.svg)

## Core Rule

> **墨色定秩序，矿物色定席位。**

ParallelMe V3 不使用「五个角色五种大色块」的配色方式。那会让产品看起来像角色卡片或心理测试。

色彩比例固定为：

- **88% 纸 / 墨 / 线**：建立阅读秩序和私密感。
- **8% 低饱和矿物席位色**：只用于识别席位。
- **4% 状态色**：只用于签字、完成、等待转正、证据链等语义状态。

## Do

- 用纸墨控制页面层级。
- 用席位色做点、线、边框和短标签。
- 所有状态都同时写文字，不靠颜色单独表达。
- 主 CTA 用 `ink.core` 或 `seal.action`。
- 签字色只留给真正有承诺重量的动作。

## Don't

- 不要把五个席位做成五张彩色大卡。
- 不要用席位色写正文。
- 不要用席位色做主按钮。
- 不要大面积使用红色表达「被流放席」。
- 不要让页面色彩密度超过内容本身。
