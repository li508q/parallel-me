# 03 · Design References

> ParallelMe 的视觉不是心理测试，也不是聊天产品。它接近“私人档案 + 仪式性会谈 + 可追溯记录”。

## 1. Liquid Glass

可借鉴：

- 轻微层次
- 当前焦点
- 状态反馈

拒绝：

- 折射导致文字不可读
- 玻璃叠玻璃
- 大面积透明工具栏

ParallelMe 方针：纸是本体，玻璃感最多出现在弹层、当前焦点和状态反馈。

参考：

- https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass
- https://linear.app/now/linear-liquid-glass
- https://infinum.com/blog/apples-ios-26-liquid-glass-sleek-shiny-and-questionably-accessible

## 2. Color

保留旧设计的核心判断：

- Quiet luxury neutrals 适合私密自我反思。
- Mineral palette 适合给五声做低饱和身份标记。
- 大部分屏幕必须由纸、墨、线控制，不让颜色抢主角。

当前五声色：

- 躺平：雨石蓝
- 搞钱：旧铜金
- 出走：杜松绿
- 讨妈欢心：茜土色
- 5 年后：烟紫

参考：

- https://colorarchive.org/collections/2026-quiet-luxury-trend/
- https://colorlabs.net/palettes/mineral-silence-2025-12-31
- https://coloruxlab.com/guides/trends-2026-january

## 3. Typography

保留双轨：

- Sans 负责操作。
- Serif 负责仪式和清明句。
- Mono 负责证据链。

规则：

- CJK letter-spacing = 0。
- 不用流体字号撑产品工作台。
- 按钮、表单、阶段轨不用 Serif。

参考：

- https://lucky.graphics/learn/serif-vs-sans-saas-2026/
- https://tabflash.com/en/typography-trends-2025/

## 4. Product Craft

Linear 启发：

- 质量来自克制和消除摩擦。
- 大多数好体验是不被看见的纸面细节。
- ProKit 式克制比视觉炫技更适合长期使用。

Things 3 启发：

- 好产品靠约束减少选择。
- “暂缓”应是一等出口，不是失败状态。

ParallelMe 对应：

- 固定五声消除“我该创建哪个角色”的焦虑。
- 四阶段减少流程噪声。
- 24h 承诺把宏大问题压成一步。

- https://linear.app/now/behind-the-latest-design-refresh
- https://blakecrosley.com/guides/design/things
