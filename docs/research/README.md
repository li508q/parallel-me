# ParallelMe Research Index

> 调研层只保留能指导 v0.7 的证据链：固定五声、书记员、本次议题、五声圆桌、清明落定，以及本地优先和心理安全边界。

当前保留四类：

- [01-foundations-psychology.md](./01-foundations-psychology.md)：IFS、Voice Dialogue、Chairwork、MI、ACT 等心理学基础与产品转译。
- [02-multi-agent-conversation.md](./02-multi-agent-conversation.md)：post-chat 交互、固定五声圆桌、书记员数据语言与用户介入。
- [03-design-references.md](./03-design-references.md)：视觉、字体、色彩、产品 craft 参考。
- [04-mental-safety.md](./04-mental-safety.md)：心理安全、隐私、竞品和技术边界。

判断标准：

- 支持固定五声，而不是扩展角色系统。
- 支持书记员作为结构化认知层。
- 支持用户低成本确认、提问、对峙和改写。
- 支持圆桌后的偏好刻画与清明落定。
- 支持本地优先和心理安全。
