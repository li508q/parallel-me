## 引用规范

- 所有引用必须有可访问 URL
- 所有数据必须标明来源年月（避免引用过期数据）
- 所有"业界共识"必须 ≥ 2 个独立来源交叉
- 单一来源的判断必须明确标注"单一来源"

## 工作纪律

1. **先档案，再实施** — 任何设计决策都要能在档案中找到出处
2. **粗读 → 精炼 → 落地** — 每份原始资料读完都要写一句"对 ParallelMe 的具体启发"
3. **冲突要标注** — 不同源建议如果冲突，写明双方观点 + 我们的选择 + 理由
4. **持续更新** — 实施过程中发现的新启发反过来更新档案
